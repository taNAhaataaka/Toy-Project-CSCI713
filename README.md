# Toy-Project-CSCI713
An AI generated toy project done for coursework in NDSU - CSCI 713

The project is an android notes app. The three functionalities the project has are allowing users to add notes, update notes, and delete notes.
A comparable project is Open Notes, which can be found at https://github.com/Fandroid745/Open-notes.git

This project used Github Copilot to generate the code in Android Studio.
